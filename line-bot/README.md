# ระบบสั่งงานคนขับผ่านไลน์ — คู่มือติดตั้ง

ระบบนี้เชื่อม 3 ส่วนเข้าด้วยกัน โดยใช้ **Google Sheet เป็นฐานข้อมูลสั่งงาน**
และ **Google Apps Script เป็นไลน์บอท** (ฟรี ไม่ต้องมีเซิร์ฟเวอร์เพิ่ม รันบนระบบของ Google จึงเสถียร)

```
พนักงานออฟฟิศ                    คนขับรถ                        เว็บ TMS (CHUEY-Server)
     │                              │                                  │
     │ ① กรอกงานในชีต «งาน»          │                                  │
     │ ─────────────► Google Sheet  │                                  │
     │                    │         │                                  │
     │            ② 17:00 ไลน์บอทแจ้งงานล่วงหน้าของพรุ่งนี้ (เก็บตก 20:00)  │
     │                    │ ───────►│                                  │
     │                    │         │ ③ รับงาน ได้ตั๋ว ถ่ายรูปส่งไลน์     │
     │                    │◄─────── │                                  │
     │            ④ OCR อ่านตัวเลข กรอกลงชีต สถานะ «ได้ตั๋วแล้ว»          │
     │                    │                                            │
     │ ⑤ ตรวจความถูกต้อง แล้วเปลี่ยนสถานะเป็น «ยืนยัน»                    │
     │ ─────────────►     │                                            │
     │                    │  ⑥ เว็บ "ดึง" เฉพาะแถวยืนยัน ไปบันทึกเป็นงานขนส่ง
     │                    │ ◄───────────────────────────────────────── │
```

**หลักที่ทำให้ระบบรัดกุม**

- OCR **ไม่เขียนลงฐานข้อมูลเว็บโดยตรง** — ต้องผ่านตาพนักงาน (ขั้น ⑤) ทุกแถว
- เว็บเป็นฝ่าย **ดึงข้อมูลเอง** (ขั้น ⑥) — เครื่อง CHUEY-Server ไม่ต้องเปิดพอร์ตสู่อินเทอร์เน็ต
- กันงานซ้ำ 2 ชั้น: สถานะในชีต + รหัสงานเป็นค่า unique ในฐานข้อมูล กดดึงซ้ำกี่ครั้งก็ไม่ซ้ำ
- ทะเบียนรถ / รหัสลูกค้า / รหัสคนขับ ในชีตเป็น dropdown ที่เว็บส่งรายการจริงมาให้ — กันพิมพ์ผิดตั้งแต่ต้นทาง

---

## ส่วนที่ 1 — สร้าง Google Sheet + ติดตั้งสคริปต์

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `สั่งงานคนขับ เทียมเทพ`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดตัวอย่างทิ้ง แล้ววางโค้ดทั้งไฟล์จาก [`Code.gs`](./Code.gs) ลงไป → กดบันทึก
4. เปิดบริการ Drive (ใช้ทำ OCR):
   ในหน้า Apps Script แถบซ้าย **Services (บริการ)** → กด **+** → เลือก **Drive API** → เลือกเวอร์ชัน **v2** → Add
5. สร้างโฟลเดอร์ใน Google Drive สำหรับเก็บรูปตั๋ว เช่น `รูปตั๋ว-เทียมเทพ`
   แล้วจดตัว id ของโฟลเดอร์ (ตัวอักษรยาว ๆ ใน URL หลัง `folders/`)

## ส่วนที่ 2 — สร้างไลน์บอท (LINE Official Account)

1. เข้า https://developers.line.biz → สร้าง **Provider** → สร้าง **Channel แบบ Messaging API**
   (ระบบจะให้สร้าง LINE Official Account ไปด้วย)
2. ในแท็บ **Messaging API** ของ channel:
   - กด **Issue** ที่หัวข้อ **Channel access token (long-lived)** → คัดลอกเก็บไว้
   - ปิด **Auto-reply messages** และ **Greeting messages** (ไปที่ LINE Official Account Manager → Response settings → เลือกตอบด้วย Webhook)
3. ยังไม่ต้องตั้ง Webhook URL — จะได้มาจากขั้นถัดไป

## ส่วนที่ 3 — ตั้งค่าลับ + เปิดใช้ webhook

1. ในหน้า Apps Script: **Project Settings (⚙) → Script Properties** เพิ่ม 4 ค่า

   | Property | ค่า |
   |---|---|
   | `LINE_CHANNEL_ACCESS_TOKEN` | token จากส่วนที่ 2 |
   | `WEBHOOK_TOKEN` | รหัสลับตั้งเอง ยาว ๆ เดายาก เช่นผลของ `openssl rand -hex 24` |
   | `DRIVE_FOLDER_ID` | id โฟลเดอร์รูปตั๋วจากส่วนที่ 1 |
   | `ADMIN_USER_ID` | (เว้นก่อนได้) LINE userId ของผู้ดูแล ไว้รับแจ้งเตือนปัญหา — ใส่ได้หลายคน คั่นด้วยจุลภาค เช่น `Uaaa...,Ubbb...` |

2. **Deploy → New deployment → ประเภท Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy → อนุญาตสิทธิ์ → คัดลอก **Web app URL**
3. นำ URL ไปตั้งเป็น Webhook URL ในหน้า LINE Developers (แท็บ Messaging API) โดย **ต่อท้ายด้วย token**:

   ```
   https://script.google.com/macros/s/XXXXX/exec?token=<WEBHOOK_TOKEN ที่ตั้งไว้>
   ```

   แล้วเปิดสวิตช์ **Use webhook** และกด **Verify** ต้องขึ้น Success

   > Apps Script ไม่เปิดให้อ่าน header จึงตรวจลายเซ็นของ LINE ไม่ได้ —
   > token ใน URL นี้คือด่านกันคนนอก ห้ามเผยแพร่ URL นี้ให้ใคร

4. กลับมาที่ชีต (รีเฟรช 1 ครั้ง) จะเห็นเมนู **🚚 ไลน์บอท**
   - กด **① สร้างโครงชีต** — ได้แท็บ งาน / คนขับ / ตั๋ว / ฐานข้อมูล / LOG พร้อม dropdown
   - กด **② ติดตั้งตัวตั้งเวลาแจ้งงาน 17:00 / 20:00** — ระบบตั้งเวลาแจ้งงาน 2 ชั้น
     (15:00 ตั้งนาฬิกาปลุก 17:00 และ 20:00 ตรง + ชั้นสำรองรายชั่วโมงส่งซ้ำเฉพาะที่ตกหล่น)
     รอบ 17:00 คือแจ้งงาน "ล่วงหน้าของวันพรุ่งนี้" ให้คนขับเตรียมตัว
     รอบ 20:00 คือรอบเก็บตก — ส่งเฉพาะแถวที่ยังไม่เคยถูกแจ้ง ไม่ส่งซ้ำคนเดิม

## ส่วนที่ 4 — เชื่อมเว็บ TMS (CHUEY-Server)

เว็บใช้ **service account** ของ Google อ่าน/เขียนชีต (ไม่ใช่รหัสผ่านส่วนตัวของใคร)

1. เข้า https://console.cloud.google.com → สร้างโปรเจกต์ (หรือใช้โปรเจกต์เดิม)
2. **APIs & Services → Enable APIs** → เปิดใช้ **Google Sheets API**
3. **IAM & Admin → Service Accounts → Create Service Account**
   ตั้งชื่อ เช่น `tiamthep-sheet` → สร้างเสร็จเข้าไปที่แท็บ **Keys → Add key → JSON** → ดาวน์โหลดไฟล์
4. เอาไฟล์ .json ไปวางบนเครื่อง CHUEY-Server **นอกโฟลเดอร์โปรเจกต์** เช่น `~/secrets/tiamthep-sheet.json`
5. เปิดไฟล์ .json ดูค่า `client_email` (ลงท้าย `...iam.gserviceaccount.com`)
   แล้วไปที่ Google Sheet → **แชร์** → ใส่อีเมลนี้ → สิทธิ์ **Editor**
6. เพิ่ม 2 บรรทัดใน `.env` ของเว็บ:

   ```
   LINE_SHEET_ID=<id ของชีต — ตัวอักษรยาวๆ ใน URL>
   GOOGLE_SERVICE_ACCOUNT_FILE=/Users/<ชื่อผู้ใช้>/secrets/tiamthep-sheet.json
   ```

7. รัน migration แล้วรีสตาร์ตเว็บ: `npm run db:migrate` → เปิดหน้า **บันทึกประจำวัน → งานจากไลน์**
   กด **ดึงงานเข้าเว็บ** 1 ครั้ง — ครั้งแรกนี้ระบบจะส่งรายชื่อ รถ / ลูกค้า / สถานที่ / คนขับ
   จากเว็บไปเติม dropdown ในชีตให้อัตโนมัติ (และจะอัปเดตทุกครั้งที่กดดึง)

## ส่วนที่ 5 — ให้คนขับลงทะเบียน

1. ให้คนขับแอดเพื่อน LINE OA ของบริษัท (แชร์ QR จากหน้า LINE Official Account Manager)
2. คนขับพิมพ์ในแชท: `ลงทะเบียน D001` (รหัสพนักงานของตัวเอง)
3. ระบบผูกไลน์กับรหัสให้ **1 รหัสต่อ 1 ไลน์เท่านั้น** — ถ้าคนขับเปลี่ยนเครื่อง/เปลี่ยนไลน์
   ให้ออฟฟิศลบค่าในคอลัมน์ *LINE User ID* ของแถวนั้น (แท็บ คนขับ) แล้วให้ลงทะเบียนใหม่

> วิธีหา userId ของผู้ดูแล (สำหรับ `ADMIN_USER_ID`): เพิ่มแถวรหัส `ADMIN` ในแท็บคนขับ
> แล้วให้ผู้ดูแลแอดบอทและพิมพ์ `ลงทะเบียน ADMIN` — ค่า userId จะปรากฏในคอลัมน์ LINE User ID
> นำไปใส่ใน Script Properties แล้วจะลบแถว ADMIN ทิ้งก็ได้

## การใช้งานประจำวัน

| เวลา | ใคร | ทำอะไร |
|---|---|---|
| ก่อน 17:00 | ออฟฟิศ | กรอกงาน **ของวันพรุ่งนี้** ในแท็บ **งาน**: วันที่ / รหัสคนขับ / ทะเบียน / ลูกค้า / เส้นทาง — รหัสงานและสถานะ «สั่งงาน» ขึ้นเอง |
| 17:00 | ระบบ | ไลน์บอทแจ้งงานล่วงหน้าของพรุ่งนี้ให้คนขับรายคน (พ่วงงานวันนี้ที่ยังไม่เคยแจ้ง) แถวเปลี่ยนเป็น «แจ้งแล้ว» — คนที่ยังไม่ลงทะเบียนไลน์ ระบบจะแจ้งผู้ดูแล |
| 20:00 | ระบบ | รอบเก็บตก — ส่งเฉพาะแถวที่ยังเป็น «สั่งงาน» (กรอกเพิ่มหลัง 17:00 หรือรอบแรกส่งพลาด) **ไม่ส่งซ้ำคนที่แจ้งไปแล้ว** |
| วันทำงาน | คนขับ | รับงาน ได้ตั๋ว → ถ่ายรูปส่งในแชทไลน์ · ระบบ OCR กรอกเลขตั๋ว/น้ำหนักให้ สถานะเป็น «ได้ตั๋วแล้ว» |
| ระหว่าง/สิ้นวัน | ออฟฟิศ | เปิดชีต เทียบตัวเลขกับรูปตั๋ว (ลิงก์ในคอลัมน์ รูปตั๋ว) แก้ให้ถูก แล้วเปลี่ยนสถานะเป็น **«ยืนยัน»** |
| สิ้นวัน | ออฟฟิศ | เข้าเว็บหน้า **งานจากไลน์** กด **ดึงงานเข้าเว็บ** — แถวที่ผ่านจะเป็น «นำเข้าแล้ว» แถวที่ติดปัญหาเป็น «นำเข้าไม่ผ่าน» พร้อมเหตุผล แก้แล้วตั้ง «ยืนยัน» ใหม่ได้ |

คำสั่งฝั่งคนขับ: พิมพ์ `งานวันนี้` หรือ `งานพรุ่งนี้` เพื่อขอดูงานซ้ำ · ส่งรูปตั๋วได้ทั้งวัน

### ดึงเข้าเว็บอัตโนมัติ (ทางเลือก)

ถ้าไม่อยากกดปุ่มเอง สั่งจาก Terminal บน CHUEY-Server ได้ด้วย `npm run sheet:import`
และตั้งเป็นงานอัตโนมัติรายชั่วโมงด้วย launchd:

```xml
<!-- ~/Library/LaunchAgents/com.tiamthep.sheetimport.plist -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.tiamthep.sheetimport</string>
  <key>ProgramArguments</key>
  <array><string>/bin/zsh</string><string>-lc</string>
    <string>cd /path/ไปยัง/โปรเจกต์ && npm run sheet:import</string></array>
  <key>StartInterval</key><integer>3600</integer>
</dict></plist>
```

โหลดด้วย `launchctl load ~/Library/LaunchAgents/com.tiamthep.sheetimport.plist`
(ระบบกันซ้ำอยู่แล้ว รันถี่แค่ไหนก็ไม่เกิดงานซ้ำ — แต่แถวจะเข้าเว็บก็ต่อเมื่อออฟฟิศกด «ยืนยัน» แล้วเท่านั้น)

## เมื่อมีปัญหา

| อาการ | ทางแก้ |
|---|---|
| คนขับไม่ได้รับแจ้งตอน 17:00 / 20:00 | ดูแท็บ LOG · เช็กว่าแถวงานเป็นวันที่พรุ่งนี้ (หรือวันนี้) และสถานะ «สั่งงาน» · เช็กว่าคนขับลงทะเบียนแล้ว (มี userId ในแท็บคนขับ) · กดเมนู «ส่งแจ้งงานที่ค้างเดี๋ยวนี้» เพื่อส่งซ้ำได้ทันที ไม่ส่งซ้ำคนที่ได้รับแล้ว |
| ส่งรูปแล้วบอทไม่ตอบ | เช็ก Webhook URL + token ใน LINE Developers (กด Verify) · ดูแท็บ LOG |
| OCR อ่านเลขผิด/อ่านไม่ได้ | เป็นเรื่องปกติของรูปถ่าย — ระบบออกแบบให้ออฟฟิศตรวจก่อนเสมอ ตัวเลขที่อ่านไม่ได้จะเว้นว่างไว้ ไม่เดา · เปิดรูปจากลิงก์ในชีตแล้วกรอกเอง |
| กด «ดึงงานเข้าเว็บ» แล้วขึ้นนำเข้าไม่ผ่าน | อ่านเหตุผลในคอลัมน์ «ผลนำเข้าเว็บ» เช่น ทะเบียน/รหัสลูกค้ายังไม่มีในเว็บ — เพิ่มในเว็บก่อน แล้วตั้งสถานะ «ยืนยัน» ใหม่ |
| เผลอกดดึงซ้ำ | ไม่เป็นไร — ระบบจำรหัสงานไว้ในฐานข้อมูล (unique) เกิดซ้ำไม่ได้ |
| แก้โค้ด Code.gs แล้ว webhook ไม่เปลี่ยน | ต้อง Deploy ใหม่แบบ **Manage deployments → Edit → เลือก New version** (ไม่ใช่สร้าง deployment ใหม่ — URL จะเปลี่ยน) |
