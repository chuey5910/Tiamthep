ไฟล์สำรองฐานข้อมูลจะถูกเขียนลงในโฟลเดอร์นี้

ระบบสำรองอัตโนมัติทุกวันเวลา 02:00 เก็บย้อนหลัง 30 วัน
สำรองเองได้ด้วย: npm run db:backup

กู้คืน:
  gunzip -c tiamthep-YYYYMMDD-HHMMSS.sql.gz | psql "$DATABASE_URL"

ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น git เพราะมีข้อมูลธุรกิจจริง
ควรก๊อปไปเก็บนอกเครื่องด้วย (external drive หรือ cloud) เผื่อเครื่องเสีย
